# Vanilla JavaScript Projects

A collection of mini frontend projects built with vanilla JavaScript, HTML, and CSS.

This repository serves as both a learning archive and a frontend playground where I practice UI components, DOM manipulation, animations, interactions, and reusable patterns without frameworks.

## Live Demo

```txt
https://dom-vanilla-js-projects.netlify.app/
```

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Git & GitHub
- Netlify

## Goals

- Improve DOM manipulation skills
- Practice component architecture without frameworks
- Build reusable UI patterns
- Strengthen frontend fundamentals
- Experiment with animations and interactions

---

## Running Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
```

Open the project folder and launch `index.html` using Live Server or your preferred local server.
